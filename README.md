## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/alvaro-sosa1432/portfolio.git
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
